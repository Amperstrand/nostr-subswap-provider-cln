# PORT-NOTES — reviving nostr-subswap-provider-cln for electrum 4.8.x

Study date: 2026-08-17. Fork base: f321x@fc90e07 (archived 2025-02).
Goal: a CURRENT electrum-protocol swap provider running as a CLN plugin,
TDD-ported against electrum 4.8.1 + the lightning-playground regtest lab,
then proven on signet. This project continues an archived upstream (credit
@f321x; vendored electrum code keeps its MIT headers).

## What it is (verified by reading the code)

Turns CLN itself into an electrum-client-compatible swap provider:
uses the CLN node's own wallet + newly-derived keys (no separate wallet,
backup, or nostr identity for the operator), announces on nostr, serves
swap requests from electrum wallets. ~10.3k lines Python; ~70% is
vendored OLD electrum internals (transaction.py 2395L, descriptor.py
1072L, lnaddr.py 563L [pre-bolt11.py era], ripemd.py 393L hand-rolled,
bip32, invoices, bitcoin…). Plugin-specific: submarine_swaps.py (944L,
adapted electrum swap manager), cln_lightning.py, cln_chain.py,
cln_swap_provider.py, chain_monitor.py, json_db.py.

Good news found during study: the two-phase protocol IS implemented
(createswap + createnormalswap + addswapinvoice all dispatched at
submarine_swaps.py:924-928), and server-side hold-invoice/prepay
machinery exists WITH tests (tests/test_hold_invoice_class.py — attach
prepay, HTLC tracking, settle, cancel-expired). The 106-byte P2WSH
script is byte-identical to current (pinned by our signet fixtures).

## Protocol delta vs electrum 4.8.1 (the actual port surface)

| Area | Plugin (2025-02) | Electrum 4.8.1 | Consequence today |
|---|---|---|---|
| Offer content | `percentage_fee`, `normal_mining_fee`, `reverse_mining_fee`, `claim_mining_fee`, `relays` | `fee_millionths`, `mining_fee`, `max_forward_amount`, `max_reverse_amount`, `pow_nonce` | **current clients REJECT its offers** (no pow_nonce → 0 bits < target 30) — bridge parseSwapServerEvent also gates on PoW |
| PoW | none | NIP-13 leading-zero-bits of sha256("electrum-"+pubkey+nonce), default target 30 | must implement + mine (nostr-pow-bench tooling exists: rust/cuda miners, electrum-generated golden vectors) |
| Offer event | kind 30315 w/ 'd' tag electrum-swapserver-<ver> | same + NOSTR_EVENT_VERSION, expiration tag, 'r' net: tag | verify tag shape; version bump |
| Transport | f321x/aionostr-electrum-fork@fix_loop | electrum_aionostr (PyPI, maintained) | dependency swap |
| NIP-04 | via aionostr fork | same scheme, kind 25582 req/resp | verify framing (reply tags) |
| Wallet keys | CLN wallet + derivation (their design — KEEP) | n/a | this is the plugin's value prop |
| python | pyln-client <25 | CLN 26.x | bump, latest-release policy |
| Vendored crypto | hand-rolled ripemd, old lnaddr/transaction | electrum + electrum_ecc pip packages | replace vendored files with imports where importable; keep MIT headers; LIBRARY POLICY: no hand-rolled ripemd |

## Port plan (TDD, per lightning-playground AGENTS.md)

- **M1 contract tests FIRST (fail now)**: pin the CURRENT protocol from
  real data — offer JSON schema + PoW (vectors from nostr-pow-bench,
  which were generated by electrum itself), method dispatch set,
  script template vs fixtures_completed_swaps.json, two-phase response
  shapes (createnormalswap/addswapinvoice fields from our live signet
  swaps). Tests live in this fork (tests/), conftest resolves
  ../electrum like lightning-playground's tests_tools.
- **M2 port to green**: offer format + pow_nonce (+ miner hook — accept
  a pre-mined nonce via config like electrum's ann_pow_nonce; mine
  in-process at low targets for tests, use nostr-pow-bench for 30-bit);
  electrum_aionostr swap; pyln-client 26; strip vendored files that are
  now importable (ripemd → electrum_ecc/hashes; lnaddr → electrum.bolt11;
  transaction → electrum.transaction where the plugin isn't CLN-wallet-
  specific). Fail-loud config, no silent fallbacks.
- **M3 regtest integration**: plugin into the lab CLN (compose volume
  mount, like the hold overlay), electrum-client as counterparty via
  lab macros (swap_d2/swAP_d1 equivalents against the plugin provider),
  bridge wiring optional (KV seed like `lab1`).
- **M4 signet**: new provider identity (CLN-derived), nonce mined via
  nostr-pow-bench (~1s GPU / ~90s rust), announce, verify a real
  electrum wallet + our bridge see it; small live swaps both directions.
- **M5 adversarial audit**: tamper vectors (invoice substitution, script
  mismatch, timeout games, prepay griefing) per testing playbook;
  findings → lightning-playground FINDINGS.md.
